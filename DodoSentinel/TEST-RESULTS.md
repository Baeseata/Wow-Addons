## 状态定义

| 状态 | 含义 |
|---|---|
| 未执行 | 尚无目标客户端实测 |
| 阻塞 | 人数、权限、场景或实现不足，尚未形成产品结论 |
| 通过 | 完整执行计划，且所需视觉/明文证据都满足判据 |
| 失败 | 可复现命中失败判据 |
| 需复测 | 结果矛盾、证据不全或客户端版本变化 |

## 证据分层

1. `DodoSentinelProbeDB` / `/dsprobe copy`：只收明文 probe 状态、命令、counter 迁移和允许的事件计数。
2. 截图/录像：证明真实团队标记、secret 文本渲染、texture route 与 placeholder 行为。
3. 测试者观察：在本模板中用自然语言记录屏幕结果，并引用截图/录像时间点。

聊天 payload、玩家身份、texture success 和真实标记回读不得进入 SavedVariables 或 copy 摘要。
**明文日志显示 counter 1→5 不等于屏幕上真的出现 1→5。**
